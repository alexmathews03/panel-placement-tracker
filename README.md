# Panel 💼

**Panel** is a cross-platform campus recruitment & placement drive tracker built with Flutter.

## Features
- **Email Parser Engine**: Automatically extracts company names, roles, stipend packages, eligible engineering branches, CGPA cutoffs, and deadlines from placement circulars.
- **Dynamic Eligibility Verification**: Real-time evaluation against student profile criteria (CGPA, active backlogs, department: CSE, CSBS, EEE, EV, ECE, EBE, ME).
- **Interactive Selection Rounds**: Track multi-stage interview rounds with custom timelines, dates, and completion toggles.
- **Centralized Deadline Calendar**: Compact calendar view with agenda management to prevent missed registration deadlines.
- **Offline Persistence**: Local storage with SharedPreferences.
